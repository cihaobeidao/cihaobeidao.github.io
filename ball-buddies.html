BALL BUDDIES

WEB-BASED 2D PLATFORMER

Ball Buddies is a 2D platformer game, in which the player moves two balls using only one controller at the same time. Players need to use walls to reposition the balls to solve the puzzles.

Engine: Unity

Role: Level Design, Programming

Collaborator: Jack Schlesinger
